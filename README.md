Yggdrasil
=========

Yggdrasil is an open-source, Arch-based Linux distribution and
homelab infrastructure platform focused on development,
cybersecurity laboratories, networking, virtualization, and
lightweight system management.

The project is built around Linux-native primitives and a
CLI-first development model.

Status
------

Early development.

The architecture, implementation, and interfaces are expected
to change substantially during development.
